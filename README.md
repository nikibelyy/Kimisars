# Смена — iOS Black PWA v2

Обновлённый интерфейс: глубокий чёрный iOS-inspired UI, Dynamic Island/safe-area, крупная типографика, стеклянная нижняя навигация, микроанимации календаря, денег, графиков и модального листа.

Иконка сделана специально для тёмного экрана: чёрный/графитовый фон + минималистичный неоновый знак.

Установка: разместить на HTTPS → Safari → Поделиться → На экран Домой.

## Зарплата и выплаты v3

Расчёт теперь соответствует описанной схеме:
- **25 числа** — сумма смен с **1 по 15 число текущего месяца**.
- **10 числа** — сумма смен с **16 числа до конца предыдущего месяца**.
- **15 числа** — отдельный аванс по желанию.
- Одна рабочая смена = **8 300 ₽**.

Например, 8 смен до 25 числа = **66 400 ₽**. 7 смен = **58 100 ₽**.
