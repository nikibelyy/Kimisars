# Смена — PWA для iPhone

Готовое автономное PWA-приложение для учёта смен по графику 2/2.

## Возможности
- 8 300 ₽ за смену по умолчанию, сумма редактируется.
- Календарь месяца с ручной отметкой рабочих дней.
- Автозаполнение графика 2/2.
- Статистика смен, начислений и накопленного дохода.
- Выплаты 10 и 25 числа.
- Аванс 15 числа по желанию.
- Данные сохраняются в `localStorage` и не требуют аккаунта.
- Тёмный glassmorphism-дизайн с iOS-inspired анимациями.
- PWA + offline cache + safe-area под Dynamic Island/нижнюю область iPhone.

## Установка на iPhone
1. Разместите папку на HTTPS-хостинге (например, GitHub Pages, Cloudflare Pages или любой статический хостинг).
2. Откройте сайт в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. Запустите приложение с домашнего экрана.

## Важно
Service Worker работает только через HTTPS или localhost. В приложении нет сервера и аккаунта — все отметки и настройки хранятся локально на устройстве.
