# График — офлайн PWA

Готовая мобильная PWA для календаря смен.

## Возможности
- календарь месяца;
- добавление, редактирование и удаление смен;
- несколько смен в один день;
- локальное сохранение через localStorage;
- Service Worker для работы без интернета после первого открытия;
- адаптация под iPhone и safe-area;
- тёмная красно-фиолетовая визуальная тема;
- анимации и нижняя мобильная панель.

## Запуск
Для Service Worker нужен HTTPS-хостинг (или localhost при разработке).
После публикации откройте сайт в Safari на iPhone → Поделиться → На экран «Домой».

Шрифт подключается из Google Fonts; для полностью автономной работы замените импорт Inter в style.css на локальный файл шрифта.
